#  NoteBot AI PDF Assistant

NoteBot is an AI-powered PDF Question Answering system that allows users to upload notes and ask questions directly from PDFs.

## Features
- Upload PDF documents
- Ask questions from notes
- Local AI model (No OpenAI cost)
- Streamlit Web Interface
- Semantic Search using FAISS

## 🛠 Tech Stack
- Python(use 3.10 version)
- Streamlit
- LangChain
- HuggingFace Transformers
- FAISS
- Sentence Transformers
